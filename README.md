## 📖 배경 스토리

인류가 사라진 지구. 남겨진 것은 수십 년치 쓰레기와 버려진 문명의 잔해뿐.

명령도, 목적도, 돌아갈 곳도 없는 로봇들이 스스로 선택한 일은 단 하나 —

**아무도 시키지 않았지만, 오늘도 쓰레기를 줍고 나무를 심고 자신만의 공간을 꾸밉니다.**

---

## 🎮 게임 소개

최대 4인이 함께 플레이하는 **2D 협동 멀티플레이어 클리닝 + 하우징 협동 게임**입니다.

- **장르**: 2D 협동 샌드박스 멀티플레이 (사이드뷰)
- **플랫폼**: PC (Windows)
- **플레이어**: 최대 4인 / 1인 싱글플레이 (AI 봇 추가 가능)
- **플레이 시간**: 1회 20~30분

### 핵심 루프
```
쓰레기 채굴(E키) → NPC 판매(F키) → 골드 획득 → 꾸미기 아이템 구매 → 배치 → 꾸미기 점수
```

### 두 구역 구조

| | 🏭 쓰레기 존 | 🏡 세이프 존 |
|--|------------|------------|
| **목적** | 쓰레기 채굴로 골드 획득 | NPC 거래 + 공간 꾸미기 |
| **분위기** | 긴장감 — 날씨 패널티, 배터리 소모 | 안도감 — 창작, 협동의 결과물 |

> 두 구역은 **텔레포터로만 이동** — "더 파밍할까, 아니면 넘어갈까"의 전략적 선택이 핵심

## ✨ 주요 기능

- **채굴 미니게임**: 쓰레기 더미에서 E키 → 랜덤 방향키 시퀀스 입력으로 아이템 드랍
- **경제 루프**: 7종 쓰레기 아이템 수거 → NPC 판매 → 꾸미기 아이템(약 50종) 구매 → 점수 획득
- **날씨 시스템**: 맑음 / 산성비 / 황사 3단계. **나무를 심을수록 날씨가 안정**, 날씨 이벤트 발생 시 미니게임 난이도 상승(+2)
- **배터리 시스템**: 채굴 시 배터리 소모, 미니게임 실패시 추가 소모, 방전 시 30초 기절, 팀원이 업고 이동 가능
- **AI 봇**: FSM + A\* 경로 탐색 기반. 빈 슬롯에 자동 배정, 팀과 함께 채굴·거래·꾸미기 수행
- **업적 시스템**: 골드 누적 / 꾸미기 점수 / 미니게임 성공 횟수 달성 시 토스트 알림

## 👥 캐릭터

| 캐릭터 | 특성 | 서사 |
|--------|------|------|
| 🔴 **알파** | 희귀 아이템 드랍률 +0.5%p | 탐사 목적 로봇. 가장 먼저 미지의 구역으로 뛰어든다. |
| 🟡 **베타** | 5% 확률 더블 드랍 | 산업용 수거 로봇. 누구보다 빠르게 쓰레기를 처리한다. |
| 🟣 **감마** | 꾸미기 점수 +1% 보정 | 도시 설계 보조 로봇. 아름다운 공간을 만드는 일을 멈추지 않는다. |
| 🔵 **델타** | NPC 판매 골드 +5% | 물류 관리 로봇. 자원을 가장 효율적으로 굴리는 팀의 살림꾼. |

> **알파+베타(채굴) / 델타(거래) / 감마(꾸미기)** 분업 시 최적 효율

## 🚀 실행 방법

1. 11주차 실행파일 폴더의 `.zip` 파일을 **한 번에 묶어서** 압축 해제합니다.
2. `Scrap&Sprout.exe`를 실행합니다.
3. **테스트 계정**: ID `test` / PW `1234`

> 멀티플레이: Host가 4자리 방 코드 생성 → Client가 코드 입력하여 참여
